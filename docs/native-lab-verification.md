# Native lab integration verification

The acceptance contract is the complete native lab capability, not a simplified
showcase schema. `lab-control-inventory.json` records the original controls before
adaptation. No Be Art project files are part of this change.

Local verification on 2026-09-09 passed: 22 regression test files, all five browser
verification pages, 27 byte-identical native/embedded canvas captures and eight
identical moving SVG captures. Original control inventories remain complete.
All eight logo effects were visually inspected on all four native backgrounds.
The staged site was also opened under `/_site/` to check repository-prefix URLs.

## Automated checks

- `npm test`: 22 regression test files, including the existing standalone lab,
  geometry, palettes, settings, image, and PNG export checks.
- `npm run check:showcase`: verifies all baseline controls/ranges/options remain;
  checks native text modes, complete state transport, validation and disposal;
  builds Pages and verifies it contains the actual source files.
- `npm run build:showcase`: verifies local relative dependencies in the staged
  repository-subpath deployment. The actual lab runtimes ship; superseded
  showcase renderers, shader snapshots, reduced schemas and SVG substitutes do not.

## Real browser checks

Serve the repository over HTTP and open `tests/browser/all.html` in a WebGL-capable
browser. It runs the following actual-page checks sequentially and reports their
results in the page. These are browser tests, not fake GPU implementations.

- `ellipse-parity.html`: original and embedded control sets; byte-identical PNG
  captures at equivalent dimensions in four palette/progression combinations and
  two animation times; complete state round-trip and atomic invalid import.
- `triangle-moving-parity.html`: original/embedded controls, four triangle light
  palettes (byte-identical PNGs), four moving palettes/arrangements at two times
  (identical SVG paths and colors), complete JSON and rejected invalid values.
- `canvas-parity.html`: all seven native geometries, all five aesthetics, richer
  generated palettes up to 16 colors, motion times, byte-identical canvas PNGs,
  complete native/shared JSON and invalid imports.
- `showcase-flow.html`: real landing page, all six directions, native controls and
  custom text; download/import round-trips, hiding/showing controls, per-direction
  drafts, reset, atomic cross-lab rejection, pause/resume, one active iframe after
  switching, and separate preview/control areas at 390×844 and 1280×900.
- `motion-and-images.html`: actual native clocks stop/resume for host pause,
  reduced motion and visibility; ellipse WebGL context is lost on disposal,
  Canvas surfaces are released, and detached moving time stops. A local Canvas
  image round-trips as a lossless resource; a malformed image is rejected without
  changing settings.

The Codex in-app browser was used during implementation. PNG comparisons inspect
both real renderers immediately after drawing at matching dimensions/time. SVG
comparisons include every native polygon's path and color. Controls are checked
in both documents, including duplicate numeric inputs generated by Triangle.

`tests/browser/text-effects.html` provides a visual comparison of all eight logo
effects across the four actual native backgrounds.

## Original text compositing reference

The pre-change Canvas HTML at commit
`87a016356167f3834817f9963df63037c703cb8c` supplies the reference implementation.
For local visual comparison, export that HTML into an ignored `_qa/` file and add
a base URL pointing to the repository root. Its original text functions and CSS
remain intact. Display it beside the new embedded Canvas at 800×500, with the
same art and text/effect controls. The optional extra typography/placement fields
stay at their native-layout defaults for this comparison.

Visual comparison includes invert and difference against the actual colored
background, the two-row Solea manifesto title, and the native logo treatments.
Positioned shared text avoids transforms/z-index so its blending remains in the
artwork's compositing context. This reference fixture is verification-only and is
not a maintained or published renderer snapshot.

## Explicit format boundary

Version-1 simplified showcase JSON cannot restore complete native lab settings
and is clearly rejected. Version 2 stores native settings plus the complete shared
text state, host pause, animation time where applicable, generated moving sites,
and local Canvas image resources. Native labs' original import/export formats
remain available through their own controls. WebGL-dependent labs still require
WebGL 2; renderer failures are reported instead of showing an approximate art
substitute.
